# Captures d'écran des pages

Dépose ici les captures, au format PNG, largeur d'environ 1400 px :

| Fichier | Contenu |
|---|---|
| `accueil.png` | `home.lan` sur un ordinateur |
| `accueil-tele.png` | `home.lan` en mode télé (`http://home.lan/?tv=1`) |
| `admin.png` | `admin.lan`, haut de la page (le portable, badge des services) |
| `admin-services.png` | `admin.lan`, bloc « Services » avec les interrupteurs |

Avant de les ajouter, vérifie qu'elles n'affichent ni prénom réel, ni adresse IP, ni domaine personnel, ni nom d'appareil. `publier.sh` vérifie le texte, mais il ne peut pas lire les images.
