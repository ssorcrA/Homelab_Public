Certificat de la maison

Installer le cadenas de sécurité

Ce petit fichier apprend à ton appareil que les adresses de la maison sont fiables. Sans lui, le navigateur affiche « connexion non sécurisée » sur les adresses en https. On l'installe une seule fois par appareil.

Choisis ton appareil
Téléphone ou tablette Android Télécharger le certificat
  1. Télécharge le certificat avec le bouton.
  2. Ouvre les Paramètres, puis Sécurité et confidentialité (ou Sécurité), puis Plus de paramètres de sécurité ou Chiffrement et identifiants.
  3. Touche Installer un certificat, puis Certificat CA, et valide l'avertissement (Installer quand même).
  4. Choisis maison-ca.crt dans les téléchargements. Le code de déverrouillage du téléphone peut être demandé.

Le menu change selon la marque : si tu ne le trouves pas, tape « certificat » dans la recherche des Paramètres.

iPhone ou iPad Télécharger le profil
  1. Ouvre cette page avec Safari, touche le bouton, puis Autoriser.
  2. Installer le profil : ouvre Réglages, touche Profil téléchargé en haut (ou Réglages > Général > VPN et gestion de l'appareil), puis Installer (trois fois) et ton code.
  3. Activer la confiance : Réglages > Général > Informations > Réglages du certificat, active l'interrupteur de « Caddy Local Authority », puis Continuer.

Sans la deuxième étape, le cadenas n'apparaît pas : c'est la plus souvent oubliée.

Ordinateur Windows Télécharger maison-ca.bat

Lire le contenu du fichier avant de le lancer

  1. Télécharge le fichier. Si le navigateur le signale, choisis Conserver : c'est un simple texte que tu peux ouvrir avec le Bloc-notes (clic droit, Modifier).
  2. Fais un clic droit dessus, puis Exécuter en tant qu'administrateur. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires puis Exécuter quand même.
  3. Quand la fenêtre affiche « Certificat installé », ferme et rouvre le navigateur.

Il utilise la commande Windows certutil -addstore Root et installe le certificat pour tout l'ordinateur. Chrome et Edge l'utilisent directement, Firefox aussi dans ses versions récentes.

Mac Télécharger maison-ca-mac.sh

Lire le contenu du script avant de le lancer

  1. Télécharge le script (il arrive dans Téléchargements).
  2. Ouvre Terminal et tape : sudo bash ~/Downloads/maison-ca-mac.sh, puis le mot de passe du Mac.
  3. Ferme et rouvre le navigateur.

Il utilise security add-trusted-cert pour ajouter le certificat au trousseau Système, en confiance « racine ».

Ordinateur Linux Télécharger maison-ca-linux.sh

Lire le contenu du script avant de le lancer

  1. Télécharge le script.
  2. Dans un terminal : sudo sh ~/Téléchargements/maison-ca-linux.sh (ou ~/Downloads/…).
  3. Il copie le certificat dans /usr/local/share/ca-certificates puis lance update-ca-certificates. Ferme et rouvre le navigateur.

Firefox et Chrome sous Linux ont parfois leur propre liste : si le cadenas manque, importe maison-ca.crt dans leurs réglages (Certificats, onglet Autorités).

Télévision

Beaucoup de télés ne permettent pas d'installer de certificat. Sur la télé, utilise l'adresse en http (par exemple http://home.lan) : elle continue de marcher.
